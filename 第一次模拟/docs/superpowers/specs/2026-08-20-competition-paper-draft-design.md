# 数学建模论文初稿整合设计规格

日期：2026-08-20

## 1. 目标与交付物

基于工作区内已经完成的题目摘要、问题重述、问题分析、模型假设、符号说明、三问模型建立与求解、结果分析、模型检验、模型评价及参考文献，重新整合为一篇结构连续、语言统一、数据一致的数学建模论文初稿。

最终交付一个可编辑 Word 文件：`运行结果_20260819/数学建模论文初稿_约25页.docx`。正文不包含附录，目标页数为 24—26 页，参考目标约 25 页。

## 2. 内容边界

论文必须包含：

1. 题目；
2. 摘要；
3. 关键词；
4. 目录；
5. 问题重述；
6. 问题分析；
7. 模型假设；
8. 符号说明；
9. 问题一模型建立、求解、结果分析与模型检验；
10. 问题二模型建立、求解、结果分析与模型检验；
11. 问题三模型建立、求解、结果分析与模型检验；
12. 模型评价；
13. 结论与建议；
14. 参考文献。

不纳入本次交付：完整程序、处理后数据表、附录图表目录及附录正文。现有代码和结果文件只作为论文内容的数据来源。

## 3. 章节与页数规划

| 内容 | 目标页数 | 主要内容 |
|---|---:|---|
| 题目、摘要、关键词 | 1 | 800—1000字摘要，问题—方法—结果—结论结构 |
| 目录 | 1 | 展示一级和二级标题及页码 |
| 问题重述与问题分析 | 2.5—3 | 背景、三问目标、整体框架及分问逻辑 |
| 模型假设与符号说明 | 2—2.5 | 5条假设、全局符号三线表 |
| 问题一 | 4—4.5 | 库存平衡模型、四级目标、结果及检验 |
| 问题二 | 4.5—5 | 双库存、低效小时、时限结果及检验 |
| 问题三 | 5—5.5 | 招聘下界、二维状态流、人员分解及检验 |
| 模型评价、结论与建议 | 2—2.5 | 优缺点、实际建议、改进方向 |
| 参考文献 | 1—1.5 | 8条已核验中外文献 |
| 合计 | 24—26 | 不含附录 |

如果首次渲染少于 24 页，优先补充模型推导逻辑、管理含义、敏感性解释和图表分析，不通过放大字号或增加空白凑页。如果超过 26 页，优先压缩重复的结果描述与表前表后空行，不删除核心公式、检验结论或最优性证明。

## 4. 内容整合规则

1. 三个模型名称固定为“库存平衡班次优化模型”“时限与低效约束排班模型”“连续工日约束人员配置优化模型”。
2. 全文统一符号：日期 $d$、小时 $h$、班次起点 $t$、问题二最低需求 $m_d$、第三问招聘人数 $R$、实际出勤 $z_d$。
3. 统一统计口径：方差为总体方差；利用率为总处理量除以理论排班能力；小时库存指小时结束后的未处理货量。
4. 有效性检验使用约束残差、整数性、独立重求解一致率和理论下界，不使用 RMSE、Kappa 或交叉验证。
5. 参考文献保持现有 8 条已核验文献，采用 GB/T 7714 顺序编码制。
6. 删除现有多个 Markdown 文件之间的重复段落，统一为国赛论文语体。

## 5. 图表设计

正文使用已有结果生成的 4 幅图：

1. 三问每日人员规模对比；
2. 问题一、二逐小时平均库存对比；
3. 第三问每日最低需求与实际出勤；
4. 员工最大连续工作天数分布。

正文设置约 8 张三线表，包括符号说明、三问核心结果、敏感性分析、有效性与鲁棒性检验、模型综合比较等。图表必须有连续编号、中文题注和正文引用，不出现只有图表而无解释的孤立对象。

## 6. Word版式

- 纸张：A4纵向；
- 页边距：上、下 2.5 cm，左、右 2.5 cm；
- 正文：小四宋体，1.25倍行距，首行缩进2字符；
- 一级标题：三号黑体；二级标题：四号黑体；三级标题：小四黑体；
- 摘要与关键词：小四宋体，关键词标签加粗；
- 表格：三线表风格，表内五号宋体，表题置于表上；
- 图片：居中，图题置于图下，优先使用矢量PDF或300 DPI PNG；
- 页眉：论文题目简称；页脚：居中连续页码；
- 公式：居中排列，重要公式右侧编号；
- 参考文献：五号宋体，悬挂缩进。

## 7. 生成与校验流程

1. 读取全部现有论文模块与结果文件；
2. 构造统一论文正文，清理重复及符号冲突；
3. 创建 DOCX，设置页面、样式、页眉页脚、目录、表格、公式与图片；
4. 渲染 DOCX 为逐页 PNG 和内部 QA 用 PDF；
5. 检查全部页面是否存在溢出、孤行、图表跨页、字体缺失、公式错位或大块空白；
6. 按实际页数调整内容密度，直到正文稳定在 24—26 页；
7. 再次渲染并逐页检查；
8. 仅交付最终 DOCX，不交付渲染中间文件。

## 8. 验收标准

- 正文页数为 24—26 页，不含附录；
- 规定模块全部存在，章节编号连续；
- 三问结果与 Excel、日志及检验文件一致；
- 581 人、13363 人日、最大冗余 53 人等关键结果无口径冲突；
- 所有图表、公式和参考文献可正常显示；
- 无未完成标记、占位符或虚构数据；
- Word 文件经过完整逐页渲染与视觉检查。

## 9. 自检结论

本规格不存在未决事项。页数口径明确为“含题目、摘要、目录和参考文献，不含附录”；论文内容、数据源、模型名称、图表数量、参考文献数量和版式要求均已固定，与用户确认的约25页标准国赛Word版一致。
