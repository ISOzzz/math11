# 三问模型建立、求解、结果分析与检验写作设计

## 1. 输出目标

为以下三个模型分别撰写“模型构建—求解方法—结果分析—模型检验”完整章节：

1. 库存平衡班次优化模型；
2. 时限与低效约束排班模型；
3. 连续工日约束人员配置优化模型。

正文约7000—9000字，使用LaTeX公式、Markdown结果表和国赛论文语体。内容必须与现有Python代码、Excel结果、独立检验和鲁棒性试验一致。

## 2. 问题一章节

### 模型构建

- 解释库存平衡模型用状态变量连接相邻小时、允许日内暂存但禁止提前处理的原理。
- 给出班次覆盖参数、班次选择与人数Big-M关联、小时在岗人数、处理能力、库存递推、库存非负和日末清零约束。
- 推导每人每天贡献8个工时，因此24小时平均在岗人数为总人数的三分之一。
- 给出四级词典序目标：总人数、峰值在岗人数、人员绝对偏差、累计库存。

### 求解与结果

- 说明使用Python、NumPy、openpyxl、SciPy `milp`及HiGHS求解器，按天分解并逐阶段固定上一级最优值。
- 报告10791人日、日均359.70人、方差3809.68、极值、峰值、利用率99.88%、库存峰值及班次起点频率。
- 给出每日货量与最优人数、货量与峰值人数的相关性。

### 检验

- 说明约束残差、整数性、30天独立重求解和`ceil(Q/200)`理论下界。
- 报告可行率、重求解一致率和最优性间隙。

## 3. 问题二章节

### 模型构建

- 推导单人班次能力为185件。
- 给出班次内低效人数分配及每人恰好一个低效小时的约束。
- 推导小时能力`25n-15l`。
- 将到货划分为早期和普通两类，分别建立处理量与库存递推。
- 给出16:00早期库存清零、24:00两类库存清零和四级词典序目标。

### 求解与结果

- 说明仍按天MILP求解，整数低效小时变量与货物变量联合优化。
- 报告11858人日、日均395.27人、方差4381.13、极值；相对问题一增加1067人日和9.89%；16天达到185件下界、14天因时间窗额外增员；利用率98.26%、库存变化及低效小时分布。
- 分析总货量、早期货量与人员需求的相关性，以及峰值人数未上升的含义。

### 检验

- 检查双库存残差、小时能力、低效小时计数、16:00和24:00库存、整数性及独立重求解。

## 4. 问题三章节

### 模型构建

- 将问题二的每日最低需求作为输入。
- 推导最大单日需求、总人日和连续8日窗口三个招聘人数下界。
- 定义连续工作天数与累计工作天数组成的状态，给出人口守恒、工作转移、休息转移、连续7天禁续班、每日覆盖和终端23天约束。
- 说明先最小化招聘人数，再最小化最大日冗余；将聚合流分解为具名员工，并映射到每日具体班次和低效小时。

### 求解与结果

- 说明状态流减少逐人0-1变量造成的对称性，并使用MILP精确求解。
- 报告三个下界516、531、581，最少招聘581人，总人日13363，日均出勤445.43人，冗余、休息、连续工日分布、全月峰值及利用率。
- 解释最大日冗余53达到计数下界，额外员工未抬高小时峰值。

### 检验

- 说明人员月历、逐人明细、班次人数与低效小时的交叉核验；30天每日最低人数和峰值深度重求解；招聘可行上界与理论下界闭合。
