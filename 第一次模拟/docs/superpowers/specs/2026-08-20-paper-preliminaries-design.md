# 论文前置章节写作设计

## 1. 目标与范围

为论文《基于多层混合整数规划的物流分拣排班问题研究》撰写以下四部分：

1. 问题重述；
2. 问题分析；
3. 模型假设；
4. 符号说明。

内容必须与已经完成的三个模型、求解代码、结果和检验口径一致，不提前写入求解结果，不直接复制原题。

## 2. 问题重述

- 篇幅约800—1200字。
- 从电商物流波动、小时级到货不均衡、人员利用率与服务时限冲突等实际痛点引入。
- 统一说明已知30天逐小时到货数据、每天设置5个8小时班次、工人每日最多参加一个班次等背景。
- 提炼三个递进子问题：当日清空条件下的日班次优化；提前截止与低效小时下的日排班；连续工日与固定月工作天数下的人员招聘和具名排班。
- 简要引用2篇2021—2026年间与仓储人员调度、劳动力规划或时间窗排班相关的可核查同行评议文献。
- 文中采用编号引用 `[1]`、`[2]`，在本节后附GB/T 7714格式参考文献条目，禁止编造作者、题名、期刊或DOI。

## 3. 问题分析

- 总篇幅控制在中文论文约1页。
- 采用“总—分”结构，开头说明三问从日内处理、约束强化到月度人员配置的递进关系。
- 各段标题固定为“问题一分析”“问题二分析”“问题三分析”。
- 每问均包含关键矛盾、思路框架、核心步骤和步骤间逻辑衔接，但不报告最终数值结果。
- 末尾给出一个文字流程图框架，使用箭头描述数据输入、模型构建、求解、检验与输出，并标注关键判断条件。

## 4. 模型假设

列出5条，每条均采用“假设内容—合理性依据—模型影响”的完整结构：

1. 附件到货数据准确且在对应小时初可用于处理；
2. 同一效率状态下工人处理能力同质且稳定；
3. 班次连续8小时、整数小时开始且不跨日；
4. 低效小时可在本人班次内统一调度，低效能力固定；
5. 货物可在当日暂存但不跨日，忽略设备、场地和货物类别差异。

每条说明其对模型可解性或现实边界的影响，避免把题目明示条件误写为未经说明的假设。

## 5. 符号说明

采用Markdown三线表表达，字段为“符号、含义、单位/取值”。按以下顺序组织：

- 集合与下标：日期、小时、班次起点、班次内小时、员工；
- 已知参数：到货量、班次覆盖参数、正常/低效效率、班次长度、早期货物截止时刻、每人月工作天数、最大连续工日；
- 第一问变量：班次是否选择、班次人数、小时处理量、库存、小时在岗人数；
- 第二问变量：低效小时人数、早期与普通货物处理量、两类库存、小时处理能力；
- 第三问变量：具名人员排班变量、招聘变量、状态流变量、每日实际出勤与冗余人数。

符号保持与现有代码和后续模型公式一致；全局变量只定义一次，避免同一符号多义。

## 6. 质量检查

- 文献年份、题名、期刊和DOI至少通过两个来源交叉核验。
- 检查问题重述与问题分析是否存在大段重复。
- 检查问题分析是否误写入求解结果。
- 检查每条模型假设是否同时包含依据和影响。
- 检查符号是否在后续三问模型中真实使用、单位是否明确。
